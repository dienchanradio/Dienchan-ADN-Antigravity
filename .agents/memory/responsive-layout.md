---
name: Responsive landing layout
description: Durable responsive layout guidance for the course landing page.
---

For the course landing page, desktop should preserve the parallel text-and-image composition, while tablet and mobile should use a text-first vertical flow with bounded image dimensions.

**Why:** The layered visual treatment can look balanced on a wide viewport but cause title wrapping or fixed CTA overlap on shorter, narrower screens.

**How to apply:** Re-check representative desktop, tablet, and mobile viewports after layout changes. Prefer in-flow actions on narrow screens so content is never hidden behind a fixed control.
